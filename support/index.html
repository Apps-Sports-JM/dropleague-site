Support

On répond sous quelques jours ouvrés. Pour une demande liée à tes données (accès, suppression), compte jusqu’à un mois.

Nous écrire

apps.mobile.sports@gmail.com

Pour un problème technique, précise le modèle de ton téléphone, la version d’Android et la version de l’application (elle est affichée dans Profil → Réglages). Ces trois informations font gagner un aller-retour.

Questions fréquentes

Je n’ai pas reçu mon code de connexion

Vérifie tes courriers indésirables. Le code est valable une heure, et le bouton « Renvoyer le code » se réactive après un court compte à rebours.

Je peux modifier un prono ?

Oui, jusqu’au coup d’envoi du match. Après, il est verrouillé.

Comment supprimer mon compte ?

Depuis l’application, ou depuis la page Supprimer mon compte.
