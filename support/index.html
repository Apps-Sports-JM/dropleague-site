Questions fréquentes

Je n'ai pas reçu mon code de connexion

Vérifie tes courriers indésirables. Le code est valable une heure, et un nouveau code ne peut être demandé qu'après soixante secondes.

Puis-je modifier un pronostic ?

Oui, jusqu'au coup d'envoi du match. Après, il est verrouillé.

Comment supprimer mon compte ?

Depuis l'application, ou depuis cette page.
